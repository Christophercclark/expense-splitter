# Expense Splitter

A utility for dividing expenses equally among participants.

## Features

- Participant names
- Equal expense distribution
- Individual payment amounts

## How to Use

Enter the total expense and participant names.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Split a known amount among two people.
- [ ] Check how uneven totals are rounded.
